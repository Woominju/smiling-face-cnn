# Smiling vs. Non-smiling Face Classification (CNN)

CNN image classifier that separates smiling and non-smiling faces (coursework, November 2023).

The notebook is in
[`deep-learning-coursework/smiling_face_non_smiling_face.ipynb`](https://github.com/Woominju/deep-learning-coursework/blob/main/smiling_face_non_smiling_face.ipynb).
It uses `ImageDataGenerator` with a `Conv2D` → `MaxPooling2D` → `Dense` network in TensorFlow/Keras.
The image data was read from Google Drive and is not included.

A follow-up GAN experiment on the same images is in
[`deep-learning-coursework/GAN_non_smile_2nd_version.ipynb`](https://github.com/Woominju/deep-learning-coursework/blob/main/GAN_non_smile_2nd_version.ipynb).
